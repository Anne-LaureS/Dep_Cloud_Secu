🛡️ Infrastructure Cloud Sécurisée — Impact Cybersécurité

Cette page a été déployée automatiquement par Ansible, orchestré depuis un pipeline GitHub Actions, sur une infrastructure provisionnée par Terraform.

Mesures de sécurité appliquées

  • IMDSv2 obligatoire — protection contre le vol d'identifiants IAM (type Capital One 2019)
  • Disque racine chiffré (EBS, encrypted = true)
  • État Terraform chiffré et verrouillé nativement (backend S3, use_lockfile)
  • Détection de secrets avant chaque commit (gitleaks)
  • Scan de misconfigurations avant chaque déploiement (trivy)
  • Accès SSH restreint à une IP nominative (hors fenêtre de déploiement CI)
  • Déploiement apply soumis à approbation humaine obligatoire
Pipeline : Format & Lint → Security → Terraform Plan → Terraform Apply → Deploy (Ansible)
Région AWS : eu-west-3 (Paris)
